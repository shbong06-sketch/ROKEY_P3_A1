# M0609 fixed fork tool — Isaac Sim 5.1.0 prototype

This bundle creates a two-tine fork consisting of a mounting plate and two rectangular tines. Geometry and collisions use URDF box primitives. There are no actuated joints or mesh dependencies.

## Files

- `build_fork.py`: adjustable dimensions and M0609 URDF integration.
- `output/fork_tool.urdf`: standalone tool example.
- `output/m0609_with_fork.urdf`: generated by you from the actual checkout's M0609 URDF.

## Build against the existing project

From the repository root:

```bash
python3 cobot3_ws/isaacpjt/smart_farm/assets/fork_tool/build_fork.py \
  --m0609-urdf cobot3_ws/isaacpjt/M0609/doosan-robot2/urdf/m0609_isaac_sim.urdf \
  --output-dir cobot3_ws/isaacpjt/smart_farm/assets/fork_tool/output
```

The original M0609 URDF defines `joint_6 -> link_6 -> tool0`. The generator adds `tool0 -> fork_tool` as a **fixed joint**, preserving the six actuated joints. It also resolves existing `/home/rokey/...` mesh paths against the actual source checkout; keep the original mesh folder with the checkout.

Import `output/m0609_with_fork.urdf` in Isaac Sim 5.1.0 with the URDF Importer, then save the resulting articulated robot as your project's USD. Check that the imported robot has six actuated joints, a rigid fixed attachment at `tool0`, and visible collisions on both tines. If the importer merges fixed joints, inspect the composed prim hierarchy rather than expecting a separate `fork_tool` articulation link.

The fork points along local **tool0 +Z**. The center of its tip is `(0, 0, 0.245)` meters from `tool0` with default dimensions. Rotate the wrist to insert this axis horizontally into the rack. Update the TCP offset in motion code; do not reuse the RG2 fingertip offset. Test each pose against the rack before running the PICK sequence.

## Default dimensions (meters)

| Quantity | Value |
|---|---:|
| Tine length | 0.220 |
| Tine width | 0.018 |
| Tine thickness | 0.012 |
| Tine center spacing | 0.090 |
| Mounting plate W × H × depth | 0.140 × 0.070 × 0.025 |
| Nominal tool mass | 0.45 kg |

For example, `--tine-spacing 0.11 --tine-length 0.18` regenerates both the standalone and combined URDF. Dimensions are initial simulation choices, **not validated M0609 mechanical flange dimensions**. The mounting plate represents a fixed connection in simulation; it does not specify bolt pattern, strength, actual load capacity, or real robot approval.

The original RG2 robot scene is a separate model. Use this fork variant instead of mounting it on top of an RG2 model. Before the lift test, give the pallet an actual clearance between supports, validate stage units in meters, check collisions, and measure total payload (tool + pallet + contents).
