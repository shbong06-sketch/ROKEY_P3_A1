A.
현재 터미널 세션이 `~/cobot3_ws` 워크스페이스만 소싱하고 있어, `mir100_navigation` 패키지가 존재하는 올바른 워크스페이스(`~/ROKEY_P3_A1/cobot3_ws`)의 환경 설정 파일이 누락되어 발생한 에러입니다. 또한, `source ~/cobot3_ws/install/setup.bash` 경로 역시 올바른 프로젝트 경로와 일치하지 않습니다.

1. **올바른 워크스페이스로 이동:**
`mir100_navigation` 패키지가 포함된 프로젝트 워크스페이스 디렉터리로 이동합니다.

```bash
cd ~/ROKEY_P3_A1/cobot3_ws

```

*검증:* 현재 경로가 `/home/rokey/ROKEY_P3_A1/cobot3_ws`로 변경되었는지 확인합니다.


2. **환경 변수 재설정 및 올바른 워크스페이스 소싱:**
환경 변수를 설정하고, `~/ROKEY_P3_A1/cobot3_ws` 워크스페이스의 `setup.bash`를 소싱합니다.

```bash
export ROS_DISTRO=jazzy
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
export FASTRTPS_DEFAULT_PROFILES_FILE=$HOME/.ros/fastdds_whitelist.xml
ros_set
source ~/ROKEY_P3_A1/cobot3_ws/install/setup.bash

```

*검증:* `ros2 pkg prefix mir100_navigation` 명령을 입력했을 때 `/home/rokey/ROKEY_P3_A1/cobot3_ws/install/mir100_navigation` 경로가 정상 출력되는지 확인합니다.


3. **통합 런치 파일 재실행:**
환경 변수가 올바르게 적용된 상태에서 통합 런치 파일을 실행합니다.

```bash
ros2 launch mir100_navigation smart_farm_all.launch.py

```

*검증:* 패키지 탐색 에러 없이 Nav2, RViz2 및 관련 노드들이 정상적으로 구동되는지 확인합니다.
