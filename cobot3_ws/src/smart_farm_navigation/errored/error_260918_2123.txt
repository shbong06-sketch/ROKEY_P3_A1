1. 최신 코드 수신, ROS 환경 설정, 빌드를 순서대로 실행한다.

PROJECT_ROOT=/home/rokey/ROKEY_P3_A1
cd "$PROJECT_ROOT"
git pull --ff-only origin feature/navigation
source /opt/ros/jazzy/setup.bash
export ROS_DOMAIN_ID=101
export LD_LIBRARY_PATH="$LD_LIBRARY_PATH:/home/rokey/isaacsim/exts/isaacsim.ros2.bridge/jazzy/lib"
cd "$PROJECT_ROOT/cobot3_ws"
colcon build --packages-select smart_farm_navigation --symlink-install
source "$PROJECT_ROOT/cobot3_ws/install/setup.bash"

2. 실행 전에 패키지와 장면 Topic을 확인한다.

ros2 pkg prefix smart_farm_navigation
ros2 topic info /cmd_vel -v
ros2 topic echo /chassis/odom --once

기대 결과
- ros2 pkg prefix가 /home/rokey/ROKEY_P3_A1/cobot3_ws/install/smart_farm_navigation 또는 동등한 설치 경로를 출력한다.
- /cmd_vel Subscription count가 1 이상이다.
- /chassis/odom 메시지에서 frame_id는 odom이고 child_frame_id는 base_link다.

3. 대기 제어 노드를 실행한다.

ros2 run smart_farm_navigation escape_controller --ros-args --params-file "$(ros2 pkg prefix smart_farm_navigation)/share/smart_farm_navigation/config/escape_controller.yaml"

기대 결과
- "Prepared for /cmd_vel; waiting for /chassis/odom" 로그가 출력된다.
- 로봇은 움직이지 않는다.
- Ctrl+C를 누르면 zero Twist를 발행하고 Python traceback 없이 종료한다.
