4. [터미널2] ROS 2 환경을 설정하고 올바른 위치에서 빌드한다.

source /opt/ros/jazzy/setup.bash

export LD_LIBRARY_PATH="$LD_LIBRARY_PATH:/home/rokey/isaacsim/exts/isaacsim.ros2.bridge/jazzy/lib"

source /home/rokey/ROKEY_P3_A1/cobot3_ws/install/setup.bash

기대 결과
- ros2 pkg prefix가 /home/rokey/ROKEY_P3_A1/cobot3_ws/install/smart_farm_navigation 또는 /home/rokey/cobot3_ws/install/smart_farm_navigation을 출력한다.

5. [터미널1 → 터미널2] 정지 상태 드리프트를 측정한다.

- 터미널1의 Isaac Sim 창에서 Play를 누른다. escape_controller는 아직 실행하지 않는다.
- Play 후 10초 이상 지난 뒤 터미널2에서 아래를 실행한다.

ros2 topic info /cmd_vel -v | grep -E 'Publisher count|Subscription count'
ros2 topic echo /chassis/odom --once --field pose.pose.position
sleep 60
ros2 topic echo /chassis/odom --once --field pose.pose.position

기대 결과
- Publisher count: 0, Subscription count: 1.
- 60초 사이 x 변화량이 0.01 m 이하다.
- 0.03 m 이상 변하면 명령 없이 로봇이 전진하는 상태다. 이 경우 터미널1의 뷰포트에서 로봇이 실제로 움직이는지 육안 확인 결과를 함께 기록한다. 1차~4차 기록에서 linear.x가 약 0.0007 m/s로 일정하게 관측되었다.

6. [터미널3] escape_controller 대기 실행과 Ctrl+C 정상 종료를 확인한다. 4차 기록에는 종료 출력이 없어 종료 수정 사항이 고피에서 검증되지 않았다.

6-1. 새 터미널3을 열고 환경을 설정한다. 터미널2의 설정은 터미널3에 전달되지 않는다.

source /opt/ros/jazzy/setup.bash

기대 결과
- ros2 pkg prefix가 4단계와 같은 경로를 출력한다. "Package not found"가 나오면 6-2를 실행하지 않고 6-1을 다시 수행한다.

6-2. 터미널3에서 노드를 실행한다.

ros2 run smart_farm_navigation escape_controller --ros-args --params-file "$(ros2 pkg prefix smart_farm_navigation)/share/smart_farm_navigation/config/escape_controller.yaml"

- "Prepared for /cmd_vel; waiting for /chassis/odom" 로그를 확인한 뒤 약 10초 후 터미널3에서 Ctrl+C를 누른다.

6-3. 터미널3에서 종료 직후 아래를 실행한다. 다른 명령을 먼저 실행하면 종료 코드가 덮어써진다.

echo "exit=$?"

기대 결과
- "Interrupted; publishing zero Twist." 로그가 출력된다.
- Traceback, RCLError 문구가 없다.
- exit=0 이다.

7. [터미널1] auto_start=true 실행에 필요한 장면 실측값을 Isaac Sim 창에서 읽어 기록한다. 먼저 Stop을 눌러 초기 상태로 되돌린 뒤 읽는다.

7-1. 로봇 초기 자세
- Stage 창에서 /World/nova_carter_ROS 를 선택한다.
- Property 창의 Transform에서 Translate (x, y, z)와 Orient 또는 Rotate (x, y, z) 값을 기록한다.

7-2. cube prim 위치와 크기
- Stage 창에서 통로를 이루는 cube prim 2개를 각각 선택한다.
- 각 prim의 전체 경로, Translate, Scale, 그리고 Cube의 size 값을 기록한다.

7-3. 차동 구동 파라미터
- Stage 창에서 /World/nova_carter_ROS/differential_drive 를 선택하고 Action Graph 창에서 연다.
- DifferentialController 노드를 선택하고 아래 입력값을 기록한다.
  wheelRadius, wheelDistance, maxLinearSpeed, maxAngularSpeed, maxWheelSpeed

7-4. 장면 캡처
- 뷰포트를 Top 시점으로 바꾼 뒤 로봇과 cube 2개, World 축이 모두 보이는 화면을 캡처한다.
- 캡처 파일은 /home/rokey/ROKEY_P3_A1/cobot3_ws/src/smart_farm_navigation/errored/scene_YYYYMMDD_HHMM.png 로 저장한다.

기대 결과
- 7-1~7-3 값이 모두 숫자로 기록된다. 하나라도 비어 있으면 auto_start=true 실행 가이드는 작성하지 않는다.

중단 및 기록
- 1단계 git pull이 실패하면 이후 단계를 진행하지 않는다.
- 4단계 colcon build 또는 ros2 pkg prefix가 실패하면 5~6단계를 진행하지 않는다.

- 어느 단계에서 중단했더라도 그때까지의 출력은 8단계로 커밋·푸시한다.
