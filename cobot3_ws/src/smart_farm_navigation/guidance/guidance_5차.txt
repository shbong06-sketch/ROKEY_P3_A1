[5차] smart_farm_nav2_01.usd 진행 현황 점검 및 다음 단계 입력값 수집 가이드

목적
- 4차까지의 결과를 기준으로, 고피 상태를 정리하고 escape_controller 대기 실행의 정상 종료를 확인한다.
- auto_start=true 실행에 필요한 장면 실측값을 수집한다. 이 가이드는 로봇 이동 명령을 발행하지 않는다.

고정 경로
- Git 프로젝트: /home/rokey/ROKEY_P3_A1
- ROS 2 workspace: /home/rokey/ROKEY_P3_A1/cobot3_ws
- 대상 장면: /home/rokey/ROKEY_P3_A1/cobot3_ws/isaacpjt/smart_farm/scenes/smart_farm_nav2_01.usd
- 오류 기록: /home/rokey/ROKEY_P3_A1/cobot3_ws/src/smart_farm_navigation/errored
- 결과 기록: 이 파일 하단의 "---" 아래에 원문을 붙여 넣는다.

사전 조건
- 모든 명령은 절대 경로를 사용한다. 셸 변수(PROJECT_ROOT 등)는 사용하지 않는다. 4차 1단계에서 변수 누락으로 저장소 루트에서 빌드가 실행된 이력이 있다.
- 3단계 이후는 Isaac Sim에서 대상 장면을 열고 Play 상태여야 한다.

1. 최신 코드를 받고, 저장소 루트에 잘못 생성된 빌드 산출물이 있는지 확인한다.

cd /home/rokey/ROKEY_P3_A1
git pull --ff-only origin feature/navigation
ls -d /home/rokey/ROKEY_P3_A1/build /home/rokey/ROKEY_P3_A1/install /home/rokey/ROKEY_P3_A1/log 2>/dev/null

기대 결과
- git pull이 "Already up to date." 또는 Fast-forward로 끝난다.
- ls -d 출력이 비어 있으면 2단계를 건너뛴다. 출력이 있으면 2단계를 수행한다.

2. (1단계에서 출력이 있을 때만) 저장소 루트의 빌드 산출물을 제거한다. 정상 빌드 위치인 /home/rokey/ROKEY_P3_A1/cobot3_ws/build, install, log는 건드리지 않는다.

rm -rf /home/rokey/ROKEY_P3_A1/build /home/rokey/ROKEY_P3_A1/install /home/rokey/ROKEY_P3_A1/log
ls -d /home/rokey/ROKEY_P3_A1/build /home/rokey/ROKEY_P3_A1/install /home/rokey/ROKEY_P3_A1/log 2>/dev/null

기대 결과
- 두 번째 ls -d 출력이 비어 있다.

3. 대상 장면이 참조하는 기본 장면 파일의 존재와 Git 추적 상태를 확인한다. smart_farm_nav2_01.usd는 내부에서 ./smart_farm_nav2.usd를 참조하나, 이 파일은 Git에 없다.

ls -la /home/rokey/ROKEY_P3_A1/cobot3_ws/isaacpjt/smart_farm/scenes/
git -C /home/rokey/ROKEY_P3_A1 status --short --ignored -- cobot3_ws/isaacpjt/smart_farm/scenes/
du -h /home/rokey/ROKEY_P3_A1/cobot3_ws/isaacpjt/smart_farm/scenes/smart_farm_nav2.usd 2>/dev/null

기대 결과
- scenes/ 안에 smart_farm_nav2.usd가 있으면 크기와 git status 표시(?? 또는 !!)를 기록한다.
- 없으면 "없음"으로 기록한다. 이 경우 Isaac Sim이 실제로 어떤 파일을 열어 장면을 구성했는지 File > Open 이력 경로를 기록한다.

4. ROS 2 환경을 설정하고 올바른 위치에서 빌드한다.

source /opt/ros/jazzy/setup.bash
export ROS_DOMAIN_ID=101
export LD_LIBRARY_PATH="$LD_LIBRARY_PATH:/home/rokey/isaacsim/exts/isaacsim.ros2.bridge/jazzy/lib"
cd /home/rokey/ROKEY_P3_A1/cobot3_ws
colcon build --packages-select smart_farm_navigation --symlink-install
source /home/rokey/ROKEY_P3_A1/cobot3_ws/install/setup.bash
ros2 pkg prefix smart_farm_navigation

기대 결과
- ros2 pkg prefix가 /home/rokey/ROKEY_P3_A1/cobot3_ws/install/smart_farm_navigation 또는 /home/rokey/cobot3_ws/install/smart_farm_navigation을 출력한다.

5. 정지 상태 드리프트를 측정한다. Isaac Sim은 Play 상태이고 escape_controller는 실행하지 않는다.

ros2 topic info /cmd_vel -v | grep -E 'Publisher count|Subscription count'
ros2 topic echo /chassis/odom --once --field pose.pose.position
sleep 60
ros2 topic echo /chassis/odom --once --field pose.pose.position

기대 결과
- Publisher count: 0, Subscription count: 1.
- 60초 사이 x 변화량이 0.01 m 이하다.
- 0.03 m 이상 변하면 명령 없이 로봇이 전진하는 상태다. 이 경우 Isaac Sim 뷰포트에서 로봇이 실제로 움직이는지 육안 확인 결과를 함께 기록한다. 1차~4차 기록에서 linear.x가 약 0.0007 m/s로 일정하게 관측되었다.

6. escape_controller 대기 실행과 Ctrl+C 정상 종료를 확인한다. 4차 기록에는 종료 출력이 없어 종료 수정 사항이 고피에서 검증되지 않았다.

ros2 run smart_farm_navigation escape_controller --ros-args --params-file "$(ros2 pkg prefix smart_farm_navigation)/share/smart_farm_navigation/config/escape_controller.yaml"

- "Prepared for /cmd_vel; waiting for /chassis/odom" 로그를 확인한 뒤 약 10초 후 Ctrl+C를 누른다.
- 종료 직후 아래를 실행한다.

echo "exit=$?"

기대 결과
- "Interrupted; publishing zero Twist." 로그가 출력된다.
- Traceback, RCLError 문구가 없다.
- exit=0 이다.

7. auto_start=true 실행에 필요한 장면 실측값을 Isaac Sim에서 읽어 기록한다. Play를 정지(Stop)한 초기 상태에서 읽는다.

7-1. 로봇 초기 자세
- Stage 창에서 /World/nova_carter_ROS 를 선택한다.
- Property 창의 Transform에서 Translate (x, y, z)와 Orient 또는 Rotate (x, y, z) 값을 기록한다.

7-2. cube prim 위치와 크기
- Stage 창에서 통로를 이루는 cube prim 2개를 각각 선택한다.
- 각 prim의 전체 경로, Translate, Scale, 그리고 Cube의 size 값을 기록한다.

7-3. 차동 구동 파라미터
- Stage 창에서 /World/nova_carter_ROS/differential_drive 를 선택하고 Action Graph 창에서 연다.
- DifferentialController 노드를 선택하고 아래 입력값을 기록한다.
  wheelRadius, wheelDistance, maxLinearSpeed, maxAngularSpeed, maxWheelSpeed

7-4. 장면 캡처
- 뷰포트를 Top 시점으로 바꾼 뒤 로봇과 cube 2개, World 축이 모두 보이는 화면을 캡처한다.
- 캡처 파일은 /home/rokey/ROKEY_P3_A1/cobot3_ws/src/smart_farm_navigation/errored/scene_YYYYMMDD_HHMM.png 로 저장한다.

기대 결과
- 7-1~7-3 값이 모두 숫자로 기록된다. 하나라도 비어 있으면 auto_start=true 실행 가이드는 작성하지 않는다.

중단 및 기록
- 1단계 git pull이 실패하면 이후 단계를 진행하지 않는다.
- 4단계 colcon build 또는 ros2 pkg prefix가 실패하면 5~6단계를 진행하지 않는다.
- 6단계에서 Traceback이 출력되면 원문 전체를 /home/rokey/ROKEY_P3_A1/cobot3_ws/src/smart_farm_navigation/errored/error_YYYYMMDD_HHMM.txt 에 저장한다.
- 정상 결과와 7단계 실측값은 이 파일 하단 "---" 아래에 붙여 넣고 feature/navigation에 커밋·푸시한다.
