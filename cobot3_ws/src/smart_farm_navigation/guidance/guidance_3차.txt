[3차] smart_farm_nav2_01.usd escape_controller 독립 대기 실행 가이드

목적
- smart_farm_nav2_01.usd의 /cmd_vel 구독 및 /chassis/odom 발행에 escape_controller가 정상 연결되는지 확인한다.
- 이 가이드는 이동 명령을 발행하지 않는 대기 시험이다.

사전 조건
- 고피에 Isaac Sim 및 ROS 2 Jazzy가 설치되어 있어야 한다.
- Git branch는 feature/navigation이어야 한다.
- Isaac Sim에서 아래 장면을 연 뒤 Play 상태로 둔다.

/home/rokey/ROKEY_P3_A1/cobot3_ws/isaacpjt/smart_farm/scenes/smart_farm_nav2_01.usd

1. 고피 터미널에서 최신 코드와 ROS 2 환경을 준비한다.

cd /home/rokey/ROKEY_P3_A1
git pull --ff-only origin feature/navigation
cd /home/rokey/cobot3_ws
ros_set
export ROS_DOMAIN_ID=101
colcon build --packages-select smart_farm_navigation --symlink-install
source install/setup.bash

2. 장면 통신을 확인한다.

ros2 topic info /cmd_vel -v
ros2 topic echo /chassis/odom --once

기대 결과
- /cmd_vel의 Subscription count가 1 이상이다.
- /chassis/odom에서 frame_id: odom, child_frame_id: base_link인 메시지를 받는다.

3. 제어 노드를 대기 상태로 실행한다.

ros2 run smart_farm_navigation escape_controller --ros-args --params-file "$(ros2 pkg prefix smart_farm_navigation)/share/smart_farm_navigation/config/escape_controller.yaml"

기대 결과
- "Prepared for /cmd_vel; waiting for /chassis/odom" 로그가 출력된다.
- 로봇은 움직이지 않는다. 기본 설정은 auto_start=false와 모든 이동값 0.0이다.
- Ctrl+C로 종료해도 Python traceback 없이 종료된다.

중단 조건
- /cmd_vel 구독자 또는 /chassis/odom 메시지가 없으면 3단계를 실행하지 않는다.
- 실패 출력은 cobot3_ws/src/smart_farm_navigation/errored/에 새 txt 파일로 원문 저장한다.

다음 단계의 입력값
- 후진/전진 속도와 시간, 반시계 회전 각속도와 시간을 실측으로 확정한 뒤 별도 가이드에서 auto_start=true 실행 명령을 제공한다.
