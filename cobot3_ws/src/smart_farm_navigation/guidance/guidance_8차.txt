- scene_check 가 하는 일: [1] /cmd_vel 구독자 수, [2] /chassis/odom 샘플(프레임·자세·타임스탬프), [3] /tf 의 odom→base_link 존재, [4] 15 s 무명령 드리프트. 마지막 줄 "RESULT: OK" 이면 통과.

[터미널 3] 탈출 동작 실행

ros_set

- 동작: 후진 0.20 m/s + 반시계 0.50 rad/s 원호 후진(후단이 우측으로) → yaw +90도에서 정지 → 보이는 정면으로 9.0 m 직진 → 정지 → 노드 자동 종료(launch 는 Ctrl+C 로 닫는다).
- 기대 로그 순서: Phase ARC_REVERSE → Phase ARC_STOP (yaw≈90) → Phase FORWARD → Escape sequence COMPLETE.
- 이동 없이 대기만 시키려면 auto_start:=true 를 뺀다.
- 재실행 전에는 터미널 1 에서 Isaac Sim 을 Ctrl+C 로 닫고 다시 띄워 초기 자세로 되돌린다. GUI 사용 시 Stop → Play.

기록
- results/ 의 check_*.txt, escape_*.txt 를 커밋·푸시한다. 스크립트가 자동으로 하지 않는다.

터미널 각 1,2,3에서 ros_set, isaac_ros의 사용에 대해 오류점이 발견돼서 지적과 동시에 고피의 '~/.bashrc'의 툴관련 추가된 설정 정보를 알려주겠음. 현재 고피에 설치되어있는 ros2와 아이작 심의 ros2 환경이 서로 다름. 설치되어있는 ros2는 jazzy고 isaac_ros의 경우엔 humble임. 큰일날 뻔 함. 이는 본 프로젝트 종료까지 고칠 수 없음. 당신이 고려해서 작업하고 이렇게 충돌이 발생할지도 모르는 환경 변수가 예상될 때는 사전에 파악되도록 실행 파일을 만들어줄 것. 내가 고피에서 실행시키면 되니까. 다음은 고피의 .bashrc 중 일부 내용:

export ROS_DISTRO=jazzy
echo "ROS_DISTRO="$ROS_DISTRO

# ==================================================
# Jazzy + Isaac Sim 환경 설정
# ===================================================

# ---------- ROS2 환경 변수 ----------
export ROS_DOMAIN_ID=101
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
export FASTRTPS_DEFAULT_PROFILES_FILE="$HOME/.ros/fastdds_whitelist.xml"

echo "ROS_DOMAIN_ID=$ROS_DOMAIN_ID"
echo "RMW_IMPLEMENTATION=$RMW_IMPLEMENTATION"
echo "FASTRTPS_DEFAULT_PROFILES_FILE=$FASTRTPS_DEFAULT_PROFILES_FILE"

# ---------- ROS2 소싱 (필요할 때만 실행) ----------
alias ros_set='source /opt/ros/jazzy/setup.bash'

# ---------- Isaac Sim ----------
alias isaac='"$HOME/isaacsim/isaac-sim.sh"'
alias isaac_python="~/isaacsim/python.sh"

# ---------- Isaac Sim ROS2 Bridge 경로 (중복 추가 방지) ----------
isaac_ros() {
    ISAAC_ROS_LIB="$HOME/isaacsim/exts/isaacsim.ros2.bridge/jazzy/lib"

    if [[ ":$LD_LIBRARY_PATH:" == *":$ISAAC_ROS_LIB:"* ]]; then
        echo "이미 등록됨: $ISAAC_ROS_LIB"
    else
        export LD_LIBRARY_PATH="$LD_LIBRARY_PATH:$ISAAC_ROS_LIB"
        echo "등록 완료: $ISAAC_ROS_LIB"
    fi
}

# >>> Codex installer >>>
export PATH="/home/rokey/.local/bin:$PATH"
# <<< Codex installer <<<
alias usdcat='/home/rokey/isaacsim/python.sh -m pxr.UsdUtils.usdcat'
