3. [실행 방법 - 코드 한 줄로 전체 환경 구동]
=================================================================================

터미널 1에서 아이작 심 열고, 메뉴 찾고, 터미널 2에서 런치하는 번거로운 과정 없이
아래의 [방법 A]로 "코드 한 줄" 실행합니다.

---------------------------------------------------------------------------------
[방법 A] 올인원 쉘 스크립트 (강력 추천 - 환경변수, USD오픈, 자동Play, Nav2까지 올인원)
---------------------------------------------------------------------------------
터미널 1:
    bash ~/ROKEY_P3_A1/cobot3_ws/src/smart_farm_navigation/scripts/run_all.sh

* 스크립트 내부 자동 동작:
  1) FastDDS, ROS_DISTRO, FASTRTPS 화이트리스트, isaac_ros 라이브러리 자동 구성
  2) ~/ROKEY_P3_A1/cobot3_ws/install/setup.bash 자동 소싱 (패키지 미발견 원천 방지)
  3) Isaac Sim 구동 -> Collected_260916_AMR_test.usd 자동 로드 -> ActionGraph 확인 -> 자동 Play(▶)
  4) /clock 토픽 유입을 감지한 직후 Nav2 및 RViz2 자동 실행
  5) Ctrl + C 입력 시 Isaac Sim과 Nav2 프로세스 일괄 정상 종료

---------------------------------------------------------------------------------
[방법 B] 수동 분할 실행을 원할 경우
---------------------------------------------------------------------------------
* 터미널 1 (Isaac Sim):
    export ROS_DISTRO=jazzy
    export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
    export FASTRTPS_DEFAULT_PROFILES_FILE=$HOME/.ros/fastdds_whitelist.xml
    isaac_ros
    "$HOME/isaacsim/isaac-sim.sh" \
        --/isaac/startup/ros_bridge_extension=isaacsim.ros2.bridge \
        --exec "$HOME/ROKEY_P3_A1/cobot3_ws/src/smart_farm_navigation/scripts/open_and_setup_stage.py --path $HOME/ROKEY_P3_A1/cobot3_ws/src/smart_farm_navigation/Collected_260916_AMR_test/260916_AMR_test.usd --start-on-play"

* 터미널 2 (Nav2 & RViz2):
    export ROS_DISTRO=jazzy
    export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
    export FASTRTPS_DEFAULT_PROFILES_FILE=$HOME/.ros/fastdds_whitelist.xml
    ros_set
    source ~/ROKEY_P3_A1/cobot3_ws/install/setup.bash

    ros2 launch mir100_navigation mir_navigation.launch.py \
        map:=/home/rokey/ROKEY_P3_A1/cobot3_ws/src/smart_farm_navigation/maps/260916_AMR_test_yaml.yaml

4. [로봇 주행 실행 - 터미널 2 (또는 터미널 3)]
=================================================================================

아이작 심과 RViz2가 켜져 맵이 정상 표시된 상태에서 주행 스크립트를 실행합니다:

    export ROS_DISTRO=jazzy
    export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
    export FASTRTPS_DEFAULT_PROFILES_FILE=$HOME/.ros/fastdds_whitelist.xml
    ros_set
    source ~/ROKEY_P3_A1/cobot3_ws/install/setup.bash

    # 스마트팜 통로 안전 좌표(X=0.0m, Y=3.0m, Yaw=90.0°)로 자동 자율 주행
    ros2 run nav_to_goal nav_to_pose

    # (참고) 원하는 다른 목적지 좌표로 직접 보내고 싶을 때:
    # ros2 run nav_to_goal nav_to_pose [목표X] [목표Y] [목표Yaw]
    # 예: ros2 run nav_to_goal nav_to_pose -1.0 2.0 0.0

5. 트러블슈팅 체크리스트
=================================================================================
1. 'Package mir100_navigation not found' 발생 시:
   -> 소싱 경로가 ~/cobot3_ws 가 아닌 '~/ROKEY_P3_A1/cobot3_ws/install/setup.bash' 이어야 합니다.
   -> 'ros2 pkg prefix mir100_navigation' 으로 정상 등록 여부를 확인하세요.

2. RViz2에서 'No map received' / 'Frame [map] does not exist' 에러 발생 시:
   -> 아이작 심의 시계(/clock)가 멈춰있어 Nav2 라이프사이클이 정지된 상태입니다.
   -> run_all.sh 를 실행하면 /clock 감지 후에 Nav2가 기동되므로 에러가 발생하지 않습니다.
