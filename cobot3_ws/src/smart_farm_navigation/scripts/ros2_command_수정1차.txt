=================================================================================

(1) 깃 코드 최신화 및 빌드:

    -> 실행 완료 시 260916_AMR_test.usd 에 /clock, /cmd_vel, /odom, TF 노드가 영구 저장되어
       이후 아이작 심을 열고 Play(▶)만 누르면 토픽이 100% 자동 발행됩니다.

3. [실행 방법 - 코드 한 줄로 전체 환경 구동]
=================================================================================

터미널 1에서 아이작 심 열고, 메뉴 찾고, 터미널 2에서 런치하는 번거로운 과정 없이
아래의 [방법 A] 또는 [방법 B] 중 편한 방식으로 "코드 한 줄" 실행합니다.

---------------------------------------------------------------------------------
[방법 A] 올인원 쉘 스크립트 (가장 추천 - FastDDS 환경변수 자동 적용)
---------------------------------------------------------------------------------
터미널 1:
    bash ~/ROKEY_P3_A1/cobot3_ws/src/smart_farm_navigation/scripts/run_all.sh

* 자동 수행 내용:
  1) ROS_DISTRO=jazzy, RMW_IMPLEMENTATION=rmw_fastrtps_cpp, FastDDS 화이트리스트 자동 설정
  2) Isaac Sim 백그라운드 자동 실행 (Collected_260916_AMR_test.usd 자동 로드 & Play 시작)
  3) 7초 대기 후 Nav2 Navigation 및 RViz2 자동 실행
  4) 작업 완료 후 터미널에서 Ctrl + C 를 누르면 Isaac Sim과 Nav2 모두 일괄 종료됨

---------------------------------------------------------------------------------
[방법 B] ROS 2 통합 런치 방식
---------------------------------------------------------------------------------
터미널 1:
    export ROS_DISTRO=jazzy
    export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
    export FASTRTPS_DEFAULT_PROFILES_FILE=$HOME/.ros/fastdds_whitelist.xml
    ros_set
    source ~/cobot3_ws/install/setup.bash

    ros2 launch mir100_navigation smart_farm_all.launch.py


=================================================================================
4. [로봇 주행 실행 - 터미널 2]
=================================================================================

환경이 모두 켜진 상태에서 새 터미널을 열고 주행 스크립트를 실행합니다:

터미널 2:
    export ROS_DISTRO=jazzy
    export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
    export FASTRTPS_DEFAULT_PROFILES_FILE=$HOME/.ros/fastdds_whitelist.xml
    ros_set
    source ~/cobot3_ws/install/setup.bash

    # 스마트팜 통로 안전 좌표(X=0.0m, Y=3.0m, Yaw=90.0°)로 자동 자율 주행
    ros2 run nav_to_goal nav_to_pose

    # (참고) 원하는 다른 목적지 좌표로 직접 보내고 싶을 때:
    # ros2 run nav_to_goal nav_to_pose [목표X] [목표Y] [목표Yaw]
    # 예: ros2 run nav_to_goal nav_to_pose -1.0 2.0 0.0

5. 트러블슈팅 및 주의사항
=================================================================================
1. RViz2에서 'No map received' / 'Frame [map] does not exist' 에러 발생 시:
   -> 아이작 심이 정지(Pause) 상태이거나 /clock 토픽이 안 들어오는 것입니다.
   -> 아이작 심 화면 좌측의 Play(▶) 버튼이 눌려 있는지 확인하세요.
   -> 터미널 1, 2 간에 FastDDS 환경변수(화이트리스트)가 일치하는지 확인하세요.

2. 패키지 빌드 시 주의:
   -> 런치 파일 이름은 mir_navigation.launch.py 이지만,
      ROS 2 패키지 이름은 반드시 'mir100_navigation' 입니다.
      (colcon build 시 --packages-select mir100_navigation 사용)
