1. [20:48 오류 정밀 분석 및 해결 사실]
---------------------------------------------------------------------------------
1) bt_navigator 크래시(-11) 해결 (핵심 원인):
   - 로그: `[bt_navigator]: Failed to create navigator... ID [ComputePathToPose] already registered`
   - 사실: Jazzy 버전의 Nav2는 내부 플러그인을 자동 로드하므로, YAML에 `plugin_lib_names`를
     명시하면 중복 등록 예외(SIGSEGV exit -11)로 bt_navigator 프로세스가 즉시 사망함.
   - 조치: `mir100_navigation_params.yaml`에서 `plugin_lib_names` 블록을 완전히 제거함.
     이로써 bt_navigator가 정상 가동되어 `Navigation: active`로 올라가며,
     RViz2 상단의 `Nav2 Goal` 버튼 및 파이썬 자율 주행 액션이 정상 작동함.

2) RViz2 No transform from [base_footprint] to [map] 해결 (아이작 심 1회 조치):
   - 원인: diag_info.txt 확인 결과, 아이작 심에서 /odom은 나오나 /tf 토픽이 결측되어
     `odom -> base_footprint` TF가 ROS 2로 전달되지 않음.
   - 조치: 아이작 심 Action Graph에서 `publish_odom` (`ROS2 Publish Odometry`) 노드 클릭 후,
     우측 Property 패널의 `Publish Transform` (또는 `publishTransform`) 항목을 체크(True)함.
     또는 `publish_tf` (`ROS2 Publish Transform Tree`) 노드의 실행 핀(Exec In)이 연결되어 있는지 확인함.
     (이후 Ctrl + S 로 저장)

3) 사용자 요구 반영 (가장 가까운 랙 정지 및 파라미터화):
   - 기본 목표값: 로봇 기준 가장 먼저 마주하는 랙의 중앙 앞 (X=0.30m, Y=-0.50m, Yaw=-90.0°)으로 변경 완료.
   - 파라미터화 완료:
     * 인자 없이 실행: 기본 랙 앞으로 이동 (`ros2 run nav_to_goal nav_to_pose`)
     * 좌표 지정 실행: `ros2 run nav_to_goal nav_to_pose <X> <Y> <Yaw(deg)>`
       예: `ros2 run nav_to_goal nav_to_pose -0.87 0.88 90` (두 랙 사이 통로)
     * RViz2 상단 `Nav2 Goal` 툴을 마우스로 클릭하여 맵 위 아무 곳이나 찍어도 즉시 자율 주행함.
