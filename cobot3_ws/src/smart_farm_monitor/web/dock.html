연결 준비

도킹 시도 기록 (거리·각도는 TurnTable 라이다 검출 면 기준 상대좌표계)

횡 오차 분포

가로축 = 횡 오차 lat_m(면 접선 방향, m), 세로축 = 시도 순서. 점선은 현재 허용치 ±0.06 m임. 초록 = 성공, 빨강 = 실패.

해석 기준

face_dist_m 검출 면 법선 방향 거리 m. 목표는 standoff_m = 0.92
yaw_err_deg 검출 면 기준 상대 yaw 오차 도. 0 이 면과 직각
lat_m 검출 면 접선 방향(횡) 오차 m. 허용 ±0.06
retry feeder_dock 의 BACKOFF 재시도 횟수(0.9 m 물러나 재정렬)
map_x / map_y / map_yaw_deg /amcl_pose, map 좌표계 로봇 자세
