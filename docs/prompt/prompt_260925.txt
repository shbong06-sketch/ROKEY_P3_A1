적용 시점:

새로 여는 터미널: 열릴 때마다 .bashrc를 자동으로 읽으므로 설정이 즉시 적용됩니다.

이미 열려 있던 터미널: 변경 사항을 모르는 상태이므로, 반드시 해당 창에서 source ~/.bashrc를 입력해야 반영됩니다.

3. [중요] 첨부하신 .bashrc 설정 중 발생할 치명적 문제 수정
제시해주신 내용 중 아래 2줄이 포함되면 VM 내부 ROS 2 통신이 완전히 마비됩니다.

Bash
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
export FASTRTPS_DEFAULT_PROFILES_FILE="$HOME/.ros/fastdds_whitelist.xml"
원인: 이전 질문에서 확인했듯 fastdds_whitelist.xml은 강의실 오프라인 랜선 IP(10.10.0.1~4)로만 통신하도록 제한하는 파일입니다.

GCP VM 내부에는 10.10.0.X 랜카드가 없기 때문에, 이 환경 변수를 켜는 순간 VM 내부의 ROS 2 노드들(토커-리스너, Isaac Sim 브리지)이 서로를 찾지 못해 모든 토픽 송수신이 먹통이 됩니다.

따라서 해당 화이트리스트 2줄을 제거한 아래 스크립트로 .bashrc에 등록해야 정상 작동합니다.

올바른 .bashrc 설정 내용
Bash
# ===================================================
# ROS2 Jazzy + Isaac Sim 환경 설정
# ===================================================

# ---------- ROS2 환경 변수 ----------
export ROS_DOMAIN_ID=50

# ---------- ROS2 소싱 (필요할 때만 실행) ----------
alias ros_set='source /opt/ros/jazzy/setup.bash'

# ---------- Isaac Sim ----------
alias isaac='"$HOME/isaacsim/isaac-sim.sh"'
alias isaac_python='"$HOME/isaacsim/python.sh"'

# ---------- Isaac Sim ROS2 Bridge 경로 (중복 추가 방지) ----------
isaac_ros() {
    ISAAC_ROS_LIB="$HOME/isaacsim/exts/isaacsim.ros2.bridge/jazzy/lib"

    if [[ ":$LD_LIBRARY_PATH:" == *":$ISAAC_ROS_LIB:"* ]]; then
        echo "이미 등록됨: $ISAAC_ROS_LIB"
    else
        export LD_LIBRARY_PATH="$LD_LIBRARY_PATH:$ISAAC_ROS_LIB"
        echo "등록 완료: $ISAAC_ROS_LIB"
    fi
}
이 내용을 .bashrc에 반영한 뒤, VS Code 터미널에서 source ~/.bashrc를 실행하고 ros_set을 입력해 작업하시면 됩니다."
