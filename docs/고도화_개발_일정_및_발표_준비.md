### 2.2 PPT 챌린지 요소 구성

발표에서는 다음 네 가지 기술 요소를 기본 챌린지로 구성한다.

1. **도킹 알고리즘**
    - RANSAC 기반 선 검출과 선 추종을 이용한 정밀 도킹 방식
2. **도킹 재시도 및 예외 처리**
    - 목표 도착 판정, 도킹 실패 감지, 재시도 조건과 복구 흐름
3. **RMPflow와 IK Solver 기반 로봇 제어 비교**
    - 두 제어 방식의 개념, 적용 목적 및 동작별 선택 이유
4. **Isaac Sim 합성 데이터를 활용한 YOLO 모델 교체 시간 단축**
    - 현실 데이터 수집 부담을 줄이고 새로운 대상에 빠르게 대응하는 학습 데이터 생성 방식

다섯 번째 챌린지는 개발 결과에 따라 다음과 같이 결정한다.

- **우선안:** ML 기반 이상 탐지
- **대체안:** 프로세스 분할 및 상태 머신 기반 작업 제어
- ML 이상 탐지가 발표 가능한 수준으로 성공하면 이를 다섯 번째 챌린지로 사용한다.
- ML 이상 탐지 결과가 부족하면 Task Manager의 공정 분할, 상태 전이, 타임아웃 및 예외 처리 구조를 다섯 번째 챌린지로 사용한다.

### 2.3 PPT 핵심 기능 및 모션 구성

최종 시나리오의 실제 공정 순서에 맞춰 다음 동작을 핵심 기능으로 제시한다.

#### TRANSFER

- AMR 리프트를 랙 높이에 맞게 이동
- M0609 포크 기반 팔레트 Pick & Place 수행
- 랙 내부 팔레트 재배치 과정 표현

#### NAVIGATION

- 검사 구역까지의 자율주행 성공 영상
- 사람 장애물이 존재하는 상황에서의 회피 또는 안전 대응 과정 포함
- 검사 스테이션 도착과 도킹 결과 확인

#### CULL

- YOLO 객체 탐지를 통해 정상·노란색·갈색 작물을 구분
- 노란색과 갈색 작물을 각각 지정된 위치로 분류하여 Place하는 동작까지 포함
- 객체 탐지 결과가 실제 CULL 작업으로 연결되는 과정을 강조

#### CONVEYOR_OUT

- 작물 Pick 여부를 인식한 뒤 컨베이어 구동
- Vision Room이 점유 중이면 후속 팔레트가 대기
- Turntable Conveyor를 공정 간 Buffer로 활용
- 검사 종료 후 컨베이어를 순차적으로 재가동하는 흐름 표현

### 2.4 발표에서 강조할 기술 요소

#### Real-to-Sim 관점의 디지털 트윈 구현

- 팔레트, 양배추, 랙, 컨베이어 등 실제 공정 설비를 반영한 환경 구성
- 에셋별 질량, 마찰, 충돌체, 중력 및 관성 등 물리 속성 적용
- 컨베이어 이동, 팔레트 정지, 로봇 Pick & Place 등 실제 공정 거동을 시뮬레이션에서 재현
- 발표 자료에는 단순 3D 모델링이 아니라 물리 기반 공정 검증 환경이라는 점을 명확히 제시

#### 객체 탐지 및 검사 자동화

- YOLO 기반 작물 상태 분류
- 슬롯 단위 검사 결과 생성
- 검사 결과와 CULL 동작의 연결
- 합성 데이터 기반 모델 교체 및 재학습 시간 단축 가능성 강조

### 2.5 영상 제작 계획
