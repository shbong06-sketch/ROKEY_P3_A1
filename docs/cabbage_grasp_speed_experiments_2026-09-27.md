## 2. 실험 설계 (적대적 검토 후)

처음 제안(요인 전반 x 시드 잡음 x 연속 운전 x 베이지안 최적화)을 아래처럼 바꿨다.

| 처음 제안 | 문제 | 바꾼 설계 |
|---|---|---|
| 시드로 잡음을 넣어 분포 생성 | 편차가 측정이 아니라 넣은 가정을 되돌려줌 | 결정론적 조건 비교, 한 회에 6칸 표본 |
| 속도·컨베이어 속도 등 시간 요인 | 설정값으로 시간이 정해져 자명 | 시뮬레이션만 답하는 물리 결과(집기·미끄러짐·흔들림)에 집중 |
| 연속 운전 모드 구현 | 처리량·대기열은 측정 분포 기반 DES 로 충분 | DES 로 대체 |
| 비전 요인 포함 | 9/27 렌더 불안정(검은 화면)으로 오염 | 집기 실험은 정답 라벨로 비전과 분리 |
| 새로 모으기부터 | 기존 31회 로그에 실패 신호가 이미 있었음 | 기존 로그로 가설을 세운 뒤 수집 |

## 5. 운반 속도 실험 (올인원, 유효 19회 + 무효 1회)

수확 → Nav2 + `feeder_dock` → 내려놓기까지만 돌리고 끊는다. 운반 시간 = navigation 명령 ~ 결과(주행 + 도킹).
안전 기준: 운반 구간에서 포기 6개의 트레이 기준 변위가 모두 **10 mm 이하**(트레이 구멍에 박힌 깊이 약 9~10 mm) + 내려놓기 성공.

### 시간은 어디에 쓰나 (팀 설정 0.3 m/s)

30.5 s 중 **도킹 18~20 s**(Nav2 정지 후 2 s 대기 → 제자리 정렬 → 0.10 m/s 후진 → 0.05 m/s 미세 접근). 최고속도를 2배로 올려도 24 s.
